# ProyectoProgra3-EmbarcadoDeNaveIntelestelar

Proyecto realizado en IntelliJ

Con plugin instalados para el manejo y la previsualizacion de los UML

Plugins:

PlanUmL Parser

Plantuml4idea


En el paquete de Documentos se encuentran el informe sobre la estructura del proyecto y dentro otro paquete con los codigos e imagenes png sobre los diagramas UML.
Ademas del archivo sobre el uso de Ia.

Luego Para la ejecucion de una Prueba se debera de ir al Paquete main, al archivo main.java, el cual contiene una muestra de la creacion de las 3 naves, creacion de una tripulacion y como esta es integrada a la nave y asistente, ademas de la creacion de algunas de las misiones con un caso de exito y otro con un el lanzamiento de una excepecion por la falta de recursos, todos estos eventos son registrados en las diferentes bitacoras y mostradas por consola.
